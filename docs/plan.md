# План сборки — Sweet Roses Telegram Mini App

Макет одобрен 03.10.2026. Сервер без внешних зависимостей (только Node.js 18+), данные — JSON-файлы в папке `data/`.

## Задачи
1. **Хранилище** `server/store.js` — чтение/атомарная запись каталога, заявок, статистики; первый запуск копирует `catalog.seed.json`.
2. **Telegram** `server/telegram.js` — проверка подписи initData (HMAC-SHA256), отправка сообщений, бот на long polling: `/start` (кнопка «Открыть каталог»), `/id`, кнопка меню.
3. **Заявки** `server/orders.js` — пересчёт цен на сервере (`public/pricing.js`), промокод только на первый заказ, валидация полей, текст заявки для менеджера.
4. **Статистика** `server/stats.js` — посетители по дням (уникальные), просмотры/корзины по товарам, заявки, конверсия.
5. **Импорт с сайта** `server/tilda.js` — обновление цен/фото/новых товаров из магазина Tilda, сохраняя ручные правки (скрытие, порядок).
6. **HTTP** `server/index.js` — статика, публичное API (`/api/catalog`, `/api/me`, `/api/promo`, `/api/orders`, `/api/track`), админ-API (`/api/admin/*`, только ADMIN_IDS), лимиты на размер запроса и частоту заявок.
7. **Тесты** `test/*.test.js` (node:test) — initData, цены/промокод, валидация, заявки end-to-end через HTTP, права админа.
8. **Проверка в браузере** — Playwright: пройти покупку и админку, скриншоты.
9. **Запуск** — `.env.example`, `Dockerfile`, `README.md` (BotFather → сервер Timeweb или Render).
